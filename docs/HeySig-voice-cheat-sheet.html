HeySig voice commands

Watch: Open the HeySig tile and tap its button. Phone: Run SIG3_VoiceCommand in Tasker.

Wait for the microphone. Say one command. Spoken replies play through the phone.

Read settings

SayRead
current programSelected program
current volumeHearing-aid volume
current balanceSound balance
current tinTinnitus level, if available
battery checkListen to both aids’ battery indications

Choose a program

SayProgram
program oneUniversal
program twoSleep
program threeNoisy
program fourOutdoor
program fiveTV
program sixVery Noisy

Names also work: set program to Universal or set program to Sleep.

Sleep program: Say program two or set program to Sleep. Saying sleep alone invokes separately configured sleep automation.

Change settings

SayAction / range
volume tenVolume 0–15
muteVolume 0
maximum volumeVolume 15
balance minus threeBalance −8 to 7
balance zeroCenter balance
balance softBalance −8
balance sharpBalance 7
tin oneTinnitus 0–15, if available
tin muteTinnitus 0
maximum tinnitusTinnitus 15

Save, restore, cancel

save settingsSave current settings
restore settingsRestore last saved settings
cancelEnd voice capture

Successful HeySig changes save automatically.

Optional automation

override on / override off / override toggle — block or release automatic changes; these do not enable automation.

noise sample — sample phone noise.

sleep / wake — apply configured sleep/wake programs when automation is enabled.

Ready: Phone unlocked, Signia available, Tasker accessibility enabled. Follow any audio-volume or Do Not Disturb instruction before retrying. Numbers can be words. Say a target number rather than “volume up/down” or “tin up/down.”
